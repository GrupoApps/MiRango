Poker Hand Matrix

Complete 169 unique poker hand combinations

How to Read the Matrix:

This matrix displays all 169 unique starting poker hands organized by rank combinations:

Pairs (Diagonal): AA, KK, QQ, etc.
Suited (Upper): AKs, AQs, etc.
Offsuit (Lower): AKo, AQo, etc.

Note: Rows represent the first card rank, columns represent the second card rank. For example, intersection of row "A" and column "K" shows AK combinations.
